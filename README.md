# Betão Fight Landing Page

Site institucional da Betão Fight desenvolvido em React, TypeScript e Vite.

## Páginas

- Início: treinos, planos, horários, professor, galeria, Personal Fight e localização.
- Produtos: camisas, luvas, bandagens, bonés e shorts para Boxe/Kickboxing.

A navegação de produtos usa `#/produtos` para funcionar também em hospedagens estáticas.

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
